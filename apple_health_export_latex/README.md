# Apple Health Export - LaTeX Study Document

Este pacote contem um documento LaTeX dividido por capitulos sobre o projeto `apple_health_export`.

## Compilar

```bash
xelatex main.tex
xelatex main.tex
```

## Estrutura

- `main.tex`: documento principal.
- `chapters/*.tex`: capitulos separados.
- `apple_health_export_study.pdf`: PDF compilado, se incluido no zip.
